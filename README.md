A clean, publishable homepage with deliberate image placeholders. It is intentionally small so real project photographs, plant stories and Dan's own words can replace placeholders over time.

## Publishing plan

1. Connect this repository to Cloudflare Pages.
2. Framework preset: **None** (plain static site).
3. Build command: leave blank.
4. Build output directory: `/` (repository root).
5. Test using the free `*.pages.dev` address.
6. When ready, connect `danielgeal.com` as the custom domain.

## Notion connection — next layer

V0.1 is deliberately static so visual structure can be agreed first.

V0.2 will read public website content from the existing Notion structure, especially:

- Plants database — already contains `Website Published`, `URL Slug`, `Photos`, `Short Description`, `Dan Notes`, etc.
- Projects database — add a small public website layer rather than exposing operational/client fields.
- Website Content Bank — selected copy, philosophy and Dan's own phrases.

Recommended website-only fields for Projects:

- Website Published
- URL Slug
- Website Title
- Website Summary
- Hero Image
- Gallery
- Featured
- Client Permission Confirmed

Private project information (client name, address, phone, email, budget, internal notes) must never be exported to the website build.

## Content rule

Do not fill the site with generic gardening copy. Replace placeholders only with real work, real observations, real images and language that sounds like Dan.
